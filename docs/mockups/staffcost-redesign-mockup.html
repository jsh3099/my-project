안 A — 인원별 카드

추천 · 입력 화면에 적합

  • 가로 스크롤 소멸 — 카드가 세로로 쌓여 노트북·태블릿에서도 성립
  • 비목별 상태가 1급 정보 — 저장됨 / 확인 필요 / 자동 / 미입력이 칩으로 보임
  • 거주 형태가 카드 색 테두리 + 칩으로 즉시 구분, 해당 없는 비목은 회색 처리
  • 증빙 스트립이 사람 단위로 붙어 "누구 증빙이 빠졌나"가 보임
  • 단점: 13명이면 세로로 길어짐 → 카드 접기 기본값 + 요약 행으로 완화

안 B — 개선된 표

대안 · 검토·대조 화면에 적합

  • 12열 → 6열로 병합 (임대+관리 합산, 산출근거는 보조 텍스트로)
  • 예본 정산서 표와 구조가 같아 대조 작업이 빠름
  • 여러 인원을 한눈에 비교 — 본사 검토 화면에 유리
  • 단점: 셀 안 입력은 여전히 비좁음 — 편집은 시트로 위임해야 성립

공통 적용 사항

  • 관리비 내역·자차 산출 등 패널을 표 안이 아닌 우측 시트로 — 잘림 문제 근본 해결 (위에서 "내역 10건" 클릭)
  • 이모지 버튼 → 아이콘+텍스트 버튼, 색상은 토큰으로 통일 (숙소=보라 / 출퇴근=하늘 / 확정=초록 / 제안=호박)
  • 자동 인식값은 호박색 "확인 필요"로 들어와 사용자가 확정하면 초록 "저장됨"으로 — 제안↔확정 구분이 색으로 유지
