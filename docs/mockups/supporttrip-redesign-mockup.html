구현 노트

주재비 카드에서 그대로 가져오는 것

  • 카드 1장 = 사람 1명 — 요약 행(이름·직종·방문 횟수·소계) + 접기/펼치기
  • 우측 시트 — 방문일별 산출 근거(경로·유가·계산식)를 시트로. 방문일 날짜 클릭으로 열림
  • 상태 칩 — 자동 오피넷 유가 조회됨 / 유가 확인 미조회(과거 날짜 캐시 없음) / 출근부 연동 방문일이 출근부에서 프리필됨
  • 증빙 스트립 — 유류·통행료 영수증, 첨부 즉시 저장

출장비에서만 다른 것

  • 출발지·편도거리·차종은 조건 바에 한 번만 — 방문일마다 반복 입력하지 않는다 (현재 화면은 인원당 1개 폼이라 동일, 유지)
  • 방문일이 행 단위 — 월별 그룹 라벨로 5개월 회차에서도 훑기 쉽게. 행 구성: 방문일 · 유가(오피넷) · 왕복유류비 · 통행료 · 일비+식비(규정 25,000+25,000) · 소계
  • 유가는 방문일별 — 예본 각주 "운행일자의 오피넷 고시 유가 적용" 그대로. 미조회 행은 호박색 칩으로 표시
  • 일비·식비는 규정액 고정이라 입력 없음 — 계산 근거만 시트에 표기

그다음 후보 (현장직원용 남은 화면)

  • 현장경비 입력 (/expenses/new) — 비목 카드 선택 → 건별 내역 입력. 관리비 내역 패턴 재사용
  • 출근부 — 첨부→자동인식→확인 3단계를 스텝 표시로. 구조는 유지
  • 본사담당자용(검토·정산 확정)은 현장직원용 완성 후
