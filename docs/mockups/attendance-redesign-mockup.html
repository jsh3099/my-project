구현 노트

주재비·출장비 카드에서 그대로 가져오는 것

  • 상태 칩 — 저장됨 서버 일치 / 인식됨 — 확인 필요 PDF 인식값 미저장 / 수기 — 확인 필요 직접 입력 미저장 / 미입력
  • 우측 시트 — 자동 인식의 월별 근거(파일·월·일수)를 시트로. 지금은 한 줄 안내문뿐이라 106일이 어디서 왔는지 안 보임
  • 색 토큰 연동 — 상주 카드 = 보라(주재비), 기술지원 카드 = 청록(출장비), 거주 형태 = 보라 숙소 / 하늘 출퇴근 칩 토글
  • 증빙 스트립 — 첨부 파일 칩 + 「+ 첨부 추가 (자동 인식)」, 미첨부면 호박색 경고 칩

출근부에서만 다른 것

  • 스텝 스트립 — ① 첨부 ② 자동 인식 확인 ③ 저장. 첨부가 원천(현장 작성·서명본)이고 입력값은 전기(轉記)라는 순서를 화면 구조로 못박음
  • 카드 = 사람이 아니라 구분(상주/기술지원) — 상주는 인원당 숫자 1개, 기술지원은 날짜 목록뿐이라 사람 카드로 쪼개면 과함. 행 단위 + 상태 칩으로 충분
  • 기성기간이 컨텍스트 바로 — 별도 패널이던 RoundPeriodEditor를 상단 바에 통합 (진행 중 회차 수정·다음 회차 시작 동작은 유지)
  • 방문일 칩 월별 그룹 — 5개월 회차에서 칩 20개가 한 줄로 늘어지던 것을 월 라벨로 묶음
  • 저장 모델 변화 없음 — 상주 합계는 회차 시작 월 레코드, 방문일은 월별 레코드 (upsertAttendance·parseAttendanceSheet 그대로)
