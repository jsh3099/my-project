구현 노트

주재비·출장비 카드에서 그대로 가져오는 것

  • 카드 = 정산 단위 — 주재비는 사람, 출장비도 사람, 현장경비는 세부항목(정산서 3-1 세부 사용내역의 표 1개 = 카드 1장)
  • 상태 칩 — 저장됨 서버 일치 / 확인 필요 입력·인식 후 미저장 / 한도 초과 불인정 발생 / 미입력
  • 우측 시트 — 계상 잔액·필수 증빙·복리후생 인정금액 산출 근거를 시트로 (표 안 패널 금지)
  • 증빙 스트립 + 증분 저장 — 첨부 즉시 업로드, 항목 단위 「○○ 저장」 버튼 (주재비 saveStaffCostItem 패턴)
  • 영수증 금액 자동 인식 — parseReceipt 확장: 첨부 시 금액·일자 추출해 내역 행 제안

현장경비에서만 다른 것 (기존 4단계 위저드 → 카드 목록)

  • 회차 전체가 한 화면 — 기존엔 1건 입력하고 목록으로 이동하는 왕복 구조. 개편안은 회차의 모든 항목·내역이 카드 목록으로 보이고, 그 자리에서 추가·수정
  • 월별 그룹 행 — 저장 단위는 기존과 동일한 월 × 세부항목 1건(expense) + items[] — createExpense·calcItemized·calcWelfare 서버 재계산 로직 그대로
  • 복리후생 한도가 카드에 상시 노출 — 월별 증빙 vs 산출(인원×한도) 비교와 불인정액을 배너로. 기존엔 저장 직전에야 경고
  • 계상 잔액이 카드 요약에 — 비목 선택 버튼에만 있던 잔액을 카드 우측 캡션으로 (잔액 초과는 빨강)
  • 통신비 「개인 휴대폰 아님」 확인 체크는 저장 버튼 옆으로 유지
