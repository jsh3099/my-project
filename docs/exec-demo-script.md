## 0. 촬영 전 반드시 처리할 것

### ⚠ 지금 상태로는 입력 장면을 찍을 수 없습니다

5회차가 **이미 본사에 제출되어 「검토중」 상태**입니다. 주재비·출장비 화면 상단에
"이미 본사에 제출되어 검토 중입니다 — 수정·저장은 되지 않습니다" 띠가 떠 있고 입력이 잠깁니다.

**해결 방법 두 가지 중 하나를 고르세요.**

| 방법 | 내용 | 장단점 |
|---|---|---|
| A. 본사 계정으로 반려 | 본사담당자로 로그인 → 제출 검토 → 반려 → 다시 입력 가능 | 빠름. 단 6~8번 장면(제출·검토·확정)을 다시 찍어야 함 |
| B. 데모 전용 현장 신설 | 「도매시장 5회차」와 같은 구조로 현장 하나 더 생성 | 원본 데이터 안전. 세팅에 시간 필요 |

**B를 권합니다.** 촬영은 한 번에 안 끝나고 여러 번 다시 찍게 되는데, A는 찍을 때마다
제출 상태를 되돌려야 합니다. 데모 전용 현장이 있으면 몇 번을 다시 찍어도 상관없습니다.

### 촬영 순서 — 화면 먼저, 목소리는 나중에

**동시에 하지 마세요.** 말하면서 클릭하면 둘 다 어색해집니다.

1. **1단계 — 무음 화면 녹화**: 대본의 클릭 순서만 보고 조작을 녹화. 말은 하지 않음
2. **2단계 — 편집**: 로딩 대기, 실수, 마우스 헤매는 구간 잘라냄
3. **3단계 — 나레이션 녹음**: 편집된 영상을 재생하면서 대본을 읽음
4. **4단계 — 길이 맞추기**: 대사가 화면보다 길면 그 구간 영상을 잠깐 정지시켜 늘림

이 순서면 **대사와 화면 길이를 억지로 맞출 필요가 없습니다.** 3단계에서 한 문장 틀리면
그 문장만 다시 읽으면 됩니다.

### 녹음 팁

- 휴대폰 이어폰 마이크로 충분합니다. 노트북 내장 마이크는 팬 소리가 들어갑니다
- 입에서 한 뼘 거리, 마이크를 입 정면이 아니라 **살짝 옆으로** 두면 파열음(ㅍ, ㅌ)이 덜 터집니다
- 문장을 틀리면 멈추지 말고 **2초 쉬었다가 그 문장부터 다시** 읽으세요. 편집에서 앞부분을 잘라내면 됩니다
- 한 번에 다 읽지 말고 장(章)별로 끊으세요

### 화면 세팅

- 실제 Chrome (미리보기 패널은 클릭 좌표가 어긋납니다)
- 해상도 1920×1080, **브라우저 확대 125%** — 임원분들이 노트북으로 볼 때 금액이 읽혀야 합니다
- 알림 끄기(집중 지원), 북마크바 숨기기, 불필요한 탭 정리
- 계정 전환용으로 **일반 창(현장직원) + 시크릿 창(본사담당자)** 미리 로그인 → `Alt+Tab`으로 2초 전환
