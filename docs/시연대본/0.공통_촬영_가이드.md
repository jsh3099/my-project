## 촬영 상태 관리 — 이 순서로 찍으세요

제출 상태에 따라 화면이 달라지므로, 촬영 순서가 중요합니다.

1. **1·2편**: 현재 상태(제출 완료) 그대로 촬영 — 현장 요약 숫자가 꽉 찬 상태
2. **3·4·5편 촬영 전**: 「본사 제출」 화면에서 **제출 취소** → 작성중 상태로 촬영
   (입력·증빙 삭제/재첨부 장면이 가능해짐)
3. **6편**: 촬영하면서 실제로 「본사 제출」 → 충족률이 채워지는 장면까지 이어서
