# 임원진 시연 영상 대본 (2026-08-16 개편본)

사이드바 항목별로 한 편씩 녹화해 이어붙인다 — **6편, 합계 약 10~11분**.
`0.공통_촬영_가이드`를 먼저 읽고 촬영 순서·상태 관리를 확인할 것.

| 파일 | 편 | 목표 길이 |
|---|---|---|
| `0.공통_촬영_가이드` | 촬영 도구·순서·체크리스트 | — |
| `1.인트로_근본목적_대본` | ① 플랫폼의 근본 목적 | 1분 ~ 1분 30초 |
| `2.현장요약_대본` | ② 현장 요약 | 1분 30초 ~ 2분 |
| `3.상주주재비_대본` | ③ 상주기술인 주재비 (카카오·오피넷) | 2분 30초 ~ 3분 |
| `4.기술지원출장비_대본` | ④ 기술지원 출장비 | 1분 ~ 1분 30초 |
| `5.현장경비_대본` | ⑤ 현장경비 입력 | 1분 ~ 1분 30초 |
| `6.본사제출_정산서출력_대본` | ⑥ 본사 제출 → 충족률 → 정산서 | 2분 ~ 2분 30초 |

**md가 원본이고 docx는 인쇄·낭독용 사본이다.** 대사를 고칠 때는 md를 고치고
docx를 다시 만든다(맑은 고딕, 나레이션은 음영 박스).

## 촬영용 데이터 준비 (다른 PC에서 처음 촬영할 때)

증빙 PDF는 저장소에 없다 — 생성기로 만든다. 바탕화면에 `테스트증빙_5회차` 폴더가 생긴다.

```
npm install
npx tsx scripts/gen-test-evidence.ts
```

## 촬영 중 주의

- 3~5편은 **제출 취소**로 작성중 상태에서, 6편은 실제로 제출하며 촬영
- ⚠ **회차 확정(승인)은 누르지 말 것** — 유일하게 되돌릴 수 없는 동작
- 화면 금액은 촬영 직전 실제 화면과 대조 (대본의 금액은 2026-08-16 실측값)

이전 단일 8분 대본(`docs/exec-demo-script.md`)은 이 폴더로 대체됐다.
